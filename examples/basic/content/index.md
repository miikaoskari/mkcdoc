# mathutil

A tiny math utility library used as the mkcdoc example project.

Use the navbar to browse the guide or jump straight to the [API reference](api.html).

## Features

- Integer addition (`mu_add`)
- Range clamping (`mu_clamp`)
- A documented `Point` struct and `PointStyle` enum

```c
#include "mathutil.h"

int sum = mu_add(2, 3);
```
